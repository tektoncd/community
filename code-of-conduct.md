# Tekton Community Code of Conduct

Tekton follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported by contacting
the [Tekton Governance Committee](./governance.md) via <tekton-code-of-conduct@googlegroups.com>.
